# ระบบพิมพ์ซองจดหมาย — CEO Factory (Thailand) Co., Ltd.

เว็บแอปสำหรับพิมพ์ซองจดหมายขนาด **10.5 × 23.5 ซม. (105×235 มม.)** พร้อมระบบบันทึกและค้นหาที่อยู่ผู้รับ
เป็นไฟล์ static (HTML/CSS/JS ล้วน ไม่ต้อง build) เชื่อมต่อฐานข้อมูลผ่าน **Supabase**
และนำขึ้นเว็บผ่าน **Netlify**

## โครงสร้างไฟล์
```
envelope-printer/
├── index.html     ← ตัวแอปทั้งหมด (ฟอร์ม + สมุดที่อยู่ + ตัวอย่างซอง + สั่งพิมพ์)
├── logo.png        ← โลโก้บริษัท (แสดงบนที่อยู่ผู้ส่งบนซอง)
├── schema.sql      ← คำสั่งสร้างตารางฐานข้อมูลใน Supabase
└── README.md       ← ไฟล์นี้
```

## ขั้นตอนที่ 1 — สร้างฐานข้อมูลใน Supabase

1. ไปที่ https://supabase.com แล้วสร้างบัญชี/โปรเจกต์ใหม่ (เลือก Region ใกล้ไทย เช่น Singapore)
2. เมื่อโปรเจกต์พร้อมแล้ว ไปที่เมนู **SQL Editor** ทางซ้าย
3. เปิดไฟล์ `schema.sql` ที่แนบมา คัดลอกทั้งหมด แล้ววางในช่อง SQL Editor
4. กด **Run** — ระบบจะสร้างตาราง `recipients` พร้อม index และสิทธิ์การเข้าถึงให้อัตโนมัติ
5. ไปที่เมนู **Settings → API** แล้วคัดลอกค่า 2 อย่างเก็บไว้:
   - **Project URL** (เช่น `https://xxxxxxxx.supabase.co`)
   - **anon public key** (คีย์ยาว ๆ ขึ้นต้นด้วย `eyJ...`)

   ค่าทั้งสองนี้จะนำไปกรอกในหน้าเว็บแอปตอนใช้งานจริง (ไม่ต้องแก้โค้ด)

> **หมายเหตุความปลอดภัย:** สคริปต์ตั้งค่าให้ anon key อ่าน/เขียนข้อมูลในตาราง `recipients`
> ได้ทั้งหมด เหมาะสำหรับใช้งานภายในบริษัท (internal tool) ที่ไม่ได้เปิดสู่สาธารณะ
> หากต้องการจำกัดสิทธิ์เพิ่มเติม (เช่น ต้อง login ก่อนใช้) แจ้งได้ จะเพิ่มระบบ Supabase Auth ให้

## ขั้นตอนที่ 2 — นำขึ้น Netlify

**วิธีที่ 1: ลากไฟล์วางตรง ๆ (เร็วที่สุด)**
1. ไปที่ https://app.netlify.com/drop
2. ลากทั้งโฟลเดอร์ `envelope-printer` ไปวาง (ต้องลากทั้งโฟลเดอร์ ไม่ใช่แค่ `index.html` เพราะต้องมี `logo.png` อยู่ที่เดียวกันด้วย ไม่งั้นโลโก้จะไม่ขึ้น)
3. Netlify จะสร้างลิงก์เว็บไซต์ให้ทันที เช่น `https://xxxx.netlify.app`

**วิธีที่ 2: เชื่อมกับ GitHub (แนะนำสำหรับใช้งานระยะยาว)**
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repository
2. ไปที่ Netlify → **Add new site → Import an existing project**
3. เลือก repository นี้ — ไม่ต้องตั้งค่า Build command / Publish directory ใด ๆ เพิ่มเติม
   (Publish directory = root ของ repo ได้เลย เพราะเป็น static site)
4. กด Deploy

## ขั้นตอนที่ 3 — ตั้งค่าเชื่อมต่อในหน้าเว็บ

1. เปิดเว็บไซต์ที่ deploy แล้ว
2. คลิก **"ตั้งค่าการเชื่อมต่อ Supabase"** (ใต้ปุ่มบันทึกที่อยู่)
3. วาง **Project URL** และ **anon public key** ที่คัดลอกไว้จากขั้นตอนที่ 1 แล้วกด "บันทึกการเชื่อมต่อ"
4. ระบบจะโหลดสมุดที่อยู่และพร้อมใช้งานทันที (ค่านี้ถูกจำไว้ในเบราว์เซอร์ของเครื่องนั้น ๆ)

## วิธีใช้งาน

- **เพิ่มผู้รับใหม่**: กรอกชื่อ + ที่อยู่ (เบอร์โทร/หมายเหตุ/ประเภทเอกสารไม่บังคับ) แล้วกด "บันทึกที่อยู่" — ระบบจะบันทึกลง Supabase และแสดงตัวอย่างซองให้ทันที
- **ประเภทเอกสาร**: เลือกได้จากช่อง "ประเภทเอกสาร" ในฟอร์ม (เอกสาร 50 ทวิ / ใบแจ้งหนี้ / ใบเสร็จรับเงิน / ใบกำกับภาษี) ข้อความจะไปแสดงบนซองใต้เบอร์โทรผู้รับโดยอัตโนมัติ
- **ค้นหาผู้รับเดิม**: พิมพ์ในช่องค้นหาด้านบนสมุดที่อยู่ (ค้นได้ทั้งชื่อ/ที่อยู่/เบอร์โทร)
- **เลือกพิมพ์**: คลิกรายชื่อในสมุดที่อยู่ → ระบบแสดงตัวอย่างซองด้านขวา → กด **"พิมพ์ซองนี้"**
- **พิมพ์ทีละหลายใบ**: ติ๊กเลือกผู้รับหลายคน (หรือกด "เลือกทั้งหมดที่แสดง") แล้วกด **"พิมพ์ที่เลือก"** — พิมพ์ครั้งเดียวได้หลายซอง คนละหน้ากระดาษ
- **แก้ไข/ลบ**: ใช้ไอคอน ✎ และ ✕ ที่แต่ละรายการในสมุดที่อยู่
- **แก้ไขที่อยู่ผู้ส่ง**: การ์ด "ที่อยู่บนซอง" ด้านซ้าย แก้ชื่อบริษัท/ที่อยู่/เบอร์โทรที่แสดงบนซองได้ทุกใบ (บันทึกไว้ในเบราว์เซอร์ของเครื่องนั้น)

## อัปเดตฐานข้อมูล (ถ้าเคยรัน schema.sql เวอร์ชันเก่า)

เวอร์ชันล่าสุดเพิ่มคอลัมน์ `doc_type` (ประเภทเอกสาร) ในตาราง `recipients`
ถ้าเคยรัน `schema.sql` ไปแล้วก่อนหน้านี้ ให้เปิด Supabase → SQL Editor แล้วรันคำสั่งนี้เพิ่ม (ไม่กระทบข้อมูลเดิม):

```sql
alter table public.recipients add column if not exists doc_type text;
```

หรือจะเปิดไฟล์ `schema.sql` ใหม่แล้วรันทั้งไฟล์อีกรอบก็ได้ เพราะทุกคำสั่งเขียนแบบ `if not exists` ไว้แล้ว ปลอดภัยรันซ้ำได้

## บันทึกการพิมพ์ (Print History)

แท็บ **"บันทึกการพิมพ์"** ที่หัวหน้าเว็บ จะเก็บประวัติทุกครั้งที่กดพิมพ์ซอง (ทั้งพิมพ์ทีละใบและพิมพ์เป็นชุด)
โดยอัตโนมัติ พร้อมให้เลือกดูตามวันที่:

- เลือกวันที่ในช่อง "เลือกวันที่" เพื่อดูเฉพาะซองที่พิมพ์ในวันนั้น (ค่าเริ่มต้นคือวันนี้)
- กด **"ดูทั้งหมด"** เพื่อล้างตัวกรองและดูประวัติล่าสุดทั้งหมด (แสดงสูงสุด 200 รายการล่าสุด)
- แต่ละรายการแสดงชื่อ/ที่อยู่ผู้รับ, เวลาที่พิมพ์, และป้ายบอกว่าเป็นการพิมพ์เดี่ยวหรือพิมพ์เป็นชุด (พร้อมจำนวนซองในชุดนั้น)

ฟีเจอร์นี้ต้องรันไฟล์ `schema.sql` เวอร์ชันล่าสุดใน Supabase SQL Editor ก่อน (มีตารางใหม่ชื่อ `print_logs`)
ถ้าเคยรัน `schema.sql` เวอร์ชันเก่าไปแล้ว ให้เปิดไฟล์ใหม่แล้ว copy **เฉพาะส่วนท้ายที่เพิ่มเข้ามา**
(ตั้งแต่ `-- ตารางบันทึกประวัติการพิมพ์ (Print Log)` เป็นต้นไป) ไปรันเพิ่มได้เลย ไม่กระทบข้อมูลเดิม

## การตั้งค่าเครื่องพิมพ์

หน้าต่างสั่งพิมพ์ตั้งขนาดกระดาษไว้ที่ **23.5 × 10.5 ซม. (105 x 235 มม.)** (แนวนอน) โดยอัตโนมัติผ่าน CSS `@page`
ขนาดนี้ไม่ตรงกับขนาดมาตรฐาน (เช่น DL 110×220 มม.) ที่มีอยู่แล้วในเบราว์เซอร์/ไดรเวอร์ส่วนใหญ่
ให้เปิด **"การตั้งค่าเพิ่มเติม" → "ขนาดกระดาษ" → "จัดการ..." (Manage custom sizes)** แล้วเพิ่มขนาดกำหนดเอง
**กว้าง 235 มม. x สูง 105 มม.** เอง (ทำครั้งเดียว เบราว์เซอร์จะจำไว้ใช้ครั้งต่อไป)
(ปิด "Fit to page" หรือ "Scale" เพื่อให้ได้ขนาดจริง 1:1)
